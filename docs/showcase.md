# 深圳 LaRoja Dota2 社区 · 站点导览（v2）

> 一个自建的群内站点：把「谁在打、谁强、什么时候开黑、吃什么」这些平时散在微信群里的信息，收成一套能查、能看、能报名的东西。
>
> 线上地址：<https://dota.playerallocationsystem.online>
> 截图基于 2026-10 版本。**深色为当前默认主题**；每页同时提供一张「亮色对照版」（文件名带 `-light`），用于演示同一套页面在不同主题下的观感。

---

## 一、这一版相比上一版的变化

| 变化 | 说明 |
| --- | --- |
| 整站深色社区风 | 新设计系统：炭黑暖灰底、低饱和深红品牌色、古铜金只给荣誉；亮色版由同一套令牌反向覆盖 |
| 赛事页重构 | 秩序册布局 + 4 个 Tab（赛事概览 / 赛程与对阵 / 参赛队伍 / 报名选手），支持**一届多个并列冠军** |
| 赛程与对阵 | 列表视图 + 对阵树视图，逐局含阵容、装备、KDA 等赛后数据（Dota2 API 回填） |
| 报名快照 | 报名时确认「本届打什么位置、多少分」，与个人档案分离；后台可代维 |
| 后台补录 | 赛事管理的报名名单支持**缺漏检测**（分数/位置/地区）与**从选手档案一键补全**，队伍卡片标注「队员 N/5 · 缺人」 |
| 访问统计升级 | 今日/昨日环比、7 日趋势图、24 小时时段分布、匿名占比、**最近注册**名单 |
| 开黑组队 | 发卡、报名、人数上限、开黑管理后台 |
| 自托管部署 | 生产环境自托管 + Nginx 访问日志 + 应用层浏览埋点（`page_views`） |

## 二、公开页面（`screenshots/public/`）

| 截图 | 页面 | 说明 |
| --- | --- | --- |
| `home` | 首页 | 「今晚谁来守高地？」Hero + 2×2 入口卡（赛事/开黑/食堂/群友实时计数）+ 近期赛事 |
| `tournaments` | 赛事列表 | 全部届次，聚合冠亚季军展示；支持 Excel 整包导入 |
| `t-overview-赛事概览` | 赛事详情 · 概览 | 秩序册式布局：赛果对阵、最终名次（支持并列冠军）、赛事信息侧栏 |
| `t-overview-赛程与对阵` | 赛事详情 · 赛程 | 列表/对阵树双视图 + 多维筛选 |
| `t-overview-参赛队伍` | 赛事详情 · 队伍 | 队伍表：名次徽标、天梯总分、成员与担任位置、替补/恩怨局标记 |
| `t-overview-报名选手` | 赛事详情 · 报名 | 报名快照名单（本届确认的位置与分数），与个人档案区分 |
| `members` | 群友信息 | 全部群友卡片：头像、天梯分、常用位置、英雄 |
| `member` | 群友详情 | 个人档案 + 比赛履历 + 出战记录（替补判定） |
| `food` | 群友美食 | 群友推荐店铺 + 饭后评价（101 条推荐） |
| `party` | 开黑组队 | 开黑卡片：模式、分段要求、时间、一键报名 |
| `login` | 登录 | 站内账号登录（HMAC 签名 Cookie 会话，30 天） |

## 三、后台页面（`screenshots/admin/`，需管理员）

| 截图 | 页面 | 说明 |
| --- | --- | --- |
| `profile` | 个人信息 | 登录后维护自己的档案（分数/位置/英雄/仇人） |
| `main` | 阵容分配 | 按届分配队伍与人员：点选入队、自动平衡、留言板 |
| `my-tournaments` | 我的赛事 | 当前账号参加过的届次与名次 |
| `admin` | 赛事管理（列表） | 全部届次的草稿式统一编辑入口 |
| `admin-tournament` | 赛事管理（单届） | 赛事信息 / 报名名单 / 队伍与队长 / 赛程与结果 四区统一保存；**缺漏检测 + 从档案补全 + 队伍缺人提示** |
| `admin-members` | 群友管理 | 补全资料 · 标注缺失 · 补录未登记账号 |
| `admin-food` | 美食管理 | 店铺与评价的增删改查、Excel 批量导入 |
| `admin-party` | 开黑管理 | 开黑卡片的下架/清理 |
| `admin-support` | 售后反馈 | 前端异常自动上报 + 用户建议工单 |
| `admin-analytics` | 访问统计 | 今日/昨日环比、7 日趋势图、时段分布、活跃用户、热门页面、**最近注册** |

## 四、截图口径

- 视口宽度 1440px，全页截图（超长列表页截至前 3200px）。
- 深色为线上默认；`-light` 为同页注入亮色令牌后的对照渲染，仅供展示主题可切换性，线上未提供切换开关。
- 第十届（数据最全的真实赛事）用作赛事页示例；开黑与售后页含少量演示数据。
